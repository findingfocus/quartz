One problem, one page, minimal code. All recipes assume the [[Starter-Template/index|Starter Template]] layout but work in a single `main.lua` too.

## Recipes

| Recipe                                            | Problem it solves                                      |
| ------------------------------------------------- | ------------------------------------------------------ |
| [[Cookbook/Movement-and-Jump\|Movement & Jump]]   | Smooth 8-way movement + gravity that feels good        |

> [!TIP]
> Each recipe ends with **When it breaks**. If your game has a bug, check the recipe's table before Googling — it's probably there.

## How to use this section

1. Build [[First-Game/index|Pong]] first so the vocabulary lands
2. Add **one** recipe at a time to your game
3. When something works, ship a web build to [[Demos/index|Demos]] and get a friend to playtest

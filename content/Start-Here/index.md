## The 4-step loop

1. **Setup** — install Love2D, open a folder, run a window. [[Setup/index\|Setup guide]]
2. **Make** — follow one guided game. [[First-Game/index\|Your first game]]
3. **Steal** — grab the template and cookbook recipes. [[Starter-Template/index|Template]] · [[Cookbook/index|Cookbook]]
4. **Share** — put it on web + desktop. [[Distribution/index\|Distribution]]

## What you need

- A computer (Windows, Mac, or Linux — all work)
- [Love2D](https://love2d.org/) (free, ~10MB)
- Any text editor ([Sublime Text](https://www.sublimetext.com/) is what I learned on)
- No money, no game engine account, no experience

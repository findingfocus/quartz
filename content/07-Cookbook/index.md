One problem, one page, minimal code. All recipes assume the [[06-Starter-Template/index|Starter Template]] layout but work in a single `main.lua` too.

## Recipes

| Recipe | Problem it solves |
| ------ | ----------------- |
| [[07-Cookbook/Movement-and-Jump\|Movement & Jump]] | Smooth 8-way movement + gravity that feels good |
| [[07-Cookbook/Collision\|Collision]] | "Did these two boxes touch?" without a physics engine |
| [[07-Cookbook/Game-States\|Game States]] | Title → play → pause → game-over without spaghetti |
| [[07-Cookbook/Audio\|Audio]] | Music + sound effects without crackles or overlap bugs |
| [[07-Cookbook/Save-and-Load\|Save & Load]] | Persist high scores + settings between sessions |
| [[07-Cookbook/Scaling-with-Push\|Scaling with Push]] | Crisp pixels on any window size |

> [!TIP]
> Each recipe ends with **When it breaks**. If your game has a bug, check the recipe's table before Googling — it's probably there.

## How to use this section

1. Build [[05-First-Game/index|Pong]] first so the vocabulary lands
2. Add **one** recipe at a time to your game
3. When something works, ship a web build to [[10-Demos/index|Demos]] and get a friend to playtest
